## 教材の中身を追加する手順

Claude Codeの実行環境は外部サイト（note.com / youtube.com 等）へ接続できないため、
URLを渡しても本文は取得できない。以下のいずれかで本文をテキスト化して渡す。

1. **note** — 記事を開いて全選択（Ctrl/⌘+A）→ コピー → チャットに貼る
2. **YouTube** — 説明欄下の「文字起こしを表示」→ 全文コピー → チャットに貼る
3. **claude.ai（通常のClaudeアプリ）** — こちらはネット制限がないため、
   無料公開されているnote記事ならURLを貼るだけで読める場合がある

貼ってもらった内容は、このディレクトリにMarkdownとして保存していく。
