# 姿勢改善サロン 開業タスクリスト（レジデンス清水／名古屋市北区）

> 週2〜3日稼働・完全予約制・低固定費モデル前提。
> 表記ルール：`- [ ] 〔優先度／実行タイミング〕タスク名：補足`
> 優先度 **高**＝これが遅れると開業日が動く／**中**＝品質と信頼に直結／**低**＝オープン後でも可

## 0. 全体スケジュール（逆算の目安）

| 週 | フェーズ | このフェーズの「終了条件」 |
|---|---|---|
| W-8〜W-7 | 内見・条件交渉 | 器具導入の**書面承諾**が取れている |
| W-6 | 申込・審査・契約 | 契約書に「事業（サロン）利用可」が明記されている |
| W-5〜W-4 | 行政手続き・床施工・器具搬入 | 床の防振施工完了、ベンチプレス設置完了 |

> **最短化のコツ**：床施工と器具搬入は「契約後すぐ」に固め、HP・予約システムは並行で進める。

## 1. 物件交渉・契約

### 内見時（この場で確認しないと後戻りできない項目）
- [ ] 〔高／内見時〕**トイレ・手洗いの有無と位置を確認**：バス・キッチンなし物件は洗面台が無いことがある。施術業として手指衛生の導線が確保できるか（専有トイレか共用か、給湯の有無）
- [ ] 〔高／内見時〕**建物構造と床を確認**：RC造か木造か、直床か二重床（置き床）か。二重床は振動が伝わりやすい
- [ ] 〔高／内見時〕**上下階・隣室の用途を確認**：真下が住居か事務所か空室か。苦情リスクの9割はここで決まる
- [ ] 〔高／内見時〕**搬入経路の実測**：エレベーターの有無・内寸、階段の幅と踊り場、玄関ドア・室内ドアの開口幅。ベンチプレスは分解搬入でも長物（シャフト182〜220cm）が通るか要確認
- [ ] 〔高／内見時〕**事業利用（SOHO）の可否**：管理規約の「住居専用条項」の有無、賃貸借契約の使用目的欄に何と書けるか
- [ ] 〔高／内見時〕**住所のWeb公開・看板・表札の可否**：Googleビジネスプロフィール登録に関わる
- [ ] 〔中／内見時〕電気容量（アンペア数）・コンセント位置・エアコンの有無と年式
- [ ] 〔中／内見時〕ネット回線：光回線導入済みか、引込工事の可否（管理会社確認事項）
- [ ] 〔中／内見時〕換気（窓・24時間換気）、日当たり、室内の匂い、天井高（ストレッチで腕を上げても当たらないか）
- [ ] 〔中／内見時〕鍵の受け渡し方法、郵便ポスト、宅配ボックス、ゴミ出しルール（事業ゴミの扱い）
- [ ] 〔中／内見時〕最寄り駅からの実測徒歩分数、近隣コインパーキングの場所と料金、駐輪スペース
- [ ] 〔低／内見時〕携帯の電波強度（決済アプリが室内で動くか）
- [ ] 〔中／内見時〕**スマホで室内を動画撮影＋寸法メモ**：内装・レイアウト検討と、後の施工見積依頼に必須

### 申込〜審査
- [ ] 〔高／申込前〕家賃3.5〜4万円を前提に**初期費用の総額を確定**（敷金・礼金・仲介手数料・保証会社・火災保険・前家賃）
- [ ] 〔高／申込前〕**同条件の類似物件を2件以上キープ**：交渉が決裂しても止まらないようにする
- [ ] 〔高／申込時〕事業内容を正直に申告（後から発覚するのが最悪。完全予約制・1対1・週数日・不特定多数の出入りが無いことを強調）
- [ ] 〔中／申込時〕フリーレント（1〜2ヶ月）と礼金圧縮を交渉：**内装工事期間分の家賃**が実質的な交渉材料
- [ ] 〔中／審査中〕開業届・確定申告書・トレーナー実績（2017年〜）の資料を提出できるよう準備

### 契約時
- [ ] 〔高／契約時〕**使用目的欄に「姿勢改善サロン（施術業）」等の事業利用が明記**されているか確認。「住居」のままの契約は絶対に避ける
- [ ] 〔高／契約時〕**原状回復の範囲を条文で確認**：床の追加施工（マット・コンパネ）が「造作」扱いにならないか、撤去義務の範囲
- [ ] 〔高／契約時〕**火災保険に借家人賠償責任＋個人賠償**が含まれているか確認
- [ ] 〔中／契約時〕解約予告期間（1ヶ月／2ヶ月／3ヶ月）と更新料の有無を確認
- [ ] 〔中／契約時〕営業可能時間帯の制限、深夜早朝の利用制限の有無を確認
- [ ] 〔中／契約直後〕契約書・重要事項説明書・承諾書一式をPDF化してクラウド保存

## 2. オーナー交渉（器具導入・防音の合意形成）★最重要

> **口頭合意は必ず書面化する。** 「言った・言わない」で退去要求まで発展するのがこの領域。

- [ ] 〔高／内見後すぐ〕**A4・1〜2枚の「設備導入計画書」を作成**：これが交渉の武器。以下を1枚にまとめる
  - [ ] 導入機材の仕様（メーカー・型番・本体重量・設置寸法・接地面積）
  - [ ] 想定される最大荷重の内訳（本体＋プレート＋利用者の合計 ○kg／設置面積 ○㎡ ＝ ○kg/㎡）
  - [ ] 床養生の断面図（下から：既存床 → ラバーマット20mm → コンパネ12mm以上 → ラバーマット20mm 等）
  - [ ] **運用ルール**：バーベルの落下・投げ下ろしを一切行わない／高重量トレーニングは実施しない／使用は補助的なストレッチとフォーム修正のみ／営業は週数日の日中帯のみ
  - [ ] 原状回復方法（マット類は敷くだけ・非固定、撤去可能であること）
  - [ ] 賠償責任保険の加入予定（証券写しを後日提出）
- [ ] 〔高／交渉時〕**「ジム」ではなく「1対1の施術サロン」として説明**：不特定多数が同時に出入りしない、音楽を大音量で流さない、機械音がしない、という点を明示
- [ ] 〔高／交渉時〕**近隣挙動の懸念に先回り**：「万一、下階・隣室から音や振動の指摘があった場合は、使用を即時停止して対策する」と自ら申し出る（信頼獲得のコスト対効果が最も高い一言）
- [ ] 〔高／契約前〕**器具設置の承諾を書面で取得**（覚書 or 特約条項）：口頭NG。「ベンチプレス1台の設置および床養生の実施を承諾する」旨を残す
- [ ] 〔中／交渉時〕床養生の費用負担と、退去時の撤去責任を明確化
- [ ] 〔中／交渉時〕看板・表札・郵便物の宛名表記の可否を確認し、可否を書面に残す
- [ ] 〔低／契約後〕管理会社・オーナーへの連絡窓口（担当者名・電話・メール）を一覧化

## 3. 行政・公的手続き

> 整体・ストレッチのサロンは**保健所の許可・届出は不要**（理美容業やあん摩マッサージ指圧などの国家資格業とは扱いが異なる）。
> ただし**広告表現の規制は受ける**ため、下記「表現チェック」は必ず実施する。

- [ ] 〔高／契約直後〕**個人事業の開業・廃業等届出書（開業届）を提出**：事業開始から1ヶ月以内、名古屋北税務署。e-Taxでも可
- [ ] 〔高／開業届と同時〕**青色申告承認申請書を提出**：開業から2ヶ月以内（期限厳守。1日でも過ぎると初年度は白色）。最大65万円控除
- [ ] 〔中／契約直後〕**事業開始等申告書**を愛知県の県税事務所へ提出（地方税分）
- [ ] 〔中／開業前〕**屋号を確定**：商標の重複がないか特許情報プラットフォーム（J-PlatPat）で軽く検索、ドメイン取得可否も同時に確認
- [ ] 〔中／開業前〕**屋号付き口座を開設**（ネット銀行が最速）＋事業用クレジットカードを分離
- [ ] 〔高／メニュー確定時〕**広告・HPの表現チェック**：「治療」「治す」「矯正」「医学的効果の断定」「ビフォーアフター写真の誤認訴求」は医療法・あはき法・景表法の抵触リスク。「施術」「ケア」「コンディショニング」「動きやすさのサポート」等に統一する
- [ ] 〔高／メニュー確定時〕**特定商取引法の該当有無を確認**：回数券・継続契約が「期間1ヶ月超 かつ 総額5万円超」になる場合、特定継続的役務提供に該当する可能性がある。該当する場合は概要書面・契約書面の交付とクーリング・オフ（8日間）対応が必要。**回避するなら、回数券は総額5万円未満または有効期間1ヶ月以内に設計する**のが最も簡単
- [ ] 〔高／開業前〕**施術者向け賠償責任保険に加入**：施術中の事故・器具による負傷・物損をカバー。証券写しをオーナーへ提出すると信頼度が上がる
- [ ] 〔中／開業前〕国民健康保険・国民年金の状況確認（法人化はまだ不要。売上が安定してから検討）
- [ ] 〔低／開業前〕インボイス（適格請求書発行事業者）登録の要否判断：**顧客が一般個人のみなら登録不要**（免税事業者のままで問題なし）。法人・経費精算の需要が出てから再検討
- [ ] 〔低／開業前〕小規模企業共済・iDeCoの検討（節税＋退職金積立）
- [ ] 〔低／開業前〕日本政策金融公庫の融資検討：低固定費モデルなら**借りない選択が最適解**の可能性が高い。設備費が自己資金で賄えるなら見送る

## 4. 内装・防音防振施工

- [ ] 〔高／契約直後〕**床施工の範囲と仕様を確定**：ベンチプレス設置エリア（最低でも機材の外周＋50cm）と、施術・ストレッチエリアで仕様を分ける
- [ ] 〔高／契約直後〕**硬質ラバーマット（20mm厚以上）を発注**：厚さ・サイズ・枚数を実測から算出。重量物なので配送日と搬入経路を確認
- [ ] 〔高／契約直後〕**コンパネ（構造用合板12mm以上）を発注・カット依頼**：ホームセンターのカットサービスで搬入サイズに合わせる
- [ ] 〔高／鍵受領後〕**床施工を実施**：ラバー → コンパネ → ラバーの層構造で荷重を面で分散。マットは非固定（原状回復のため接着しない）
- [ ] 〔高／施工後〕**施工写真を撮影してオーナーへ共有**：「約束通り実施した」証跡。信頼残高の積み立てになる
- [ ] 〔中／施工後〕**振動テストを実施**：可能なら下階に協力してもらい、通常施術の動作で音・振動が伝わらないことを確認。ダメなら追加のラバー層で対策
- [ ] 〔中／契約後〕ドアの隙間テープ、遮音カーテンの設置（会話のプライバシー確保＝隣室が住居の場合は必須級）
- [ ] 〔中／契約後〕**姿勢撮影スペースの整備**：白または無地の壁面、正面・側面が撮れる距離、垂直基準になるライン。ビフォーアフター記録の質が集客に直結する
- [ ] 〔中／契約後〕照明の調整（色温度を統一。安価なLEDシーリング＋間接照明で「清潔感」は十分に出る）
- [ ] 〔中／契約後〕鏡の設置（飛散防止フィルム付き・軽量タイプ。壁への固定方法は原状回復可能な方式で）
- [ ] 〔低／契約後〕着替えスペース（パーテーション or ロールカーテン）、荷物置き、ハンガーラック
- [ ] 〔低／契約後〕壁の傷防止（器具が接触する面に養生）、消臭・空気清浄

## 5. 備品・器具調達・搬入

- [ ] 〔高／契約直後〕**ベンチプレスの搬入日程を確定**：床施工完了後に搬入すること（順序を間違えると二度手間）。分解状態での搬入可否を販売店に確認
- [ ] 〔高／搬入時〕搬入経路の養生（共用部の床・壁・エレベーター内）。ここで傷をつけると交渉の努力が水の泡
- [ ] 〔高／契約直後〕**施術ベッド**（折りたたみ or 固定式）：室内寸法と動線に合うサイズを実測してから発注
- [ ] 〔中／契約直後〕プレートは**ラバーコーティングまたはウレタン製**を選定（金属プレートは接触音が大きい）。低負荷用途なら軽量のみで十分
- [ ] 〔中／契約直後〕ストレッチマット、フォームローラー、ストレッチポール、セラバンド、軽量ダンベル、ヨガブロック
- [ ] 〔中／契約直後〕タオル類（フェイス・バスタオル各10枚程度）、洗濯導線の確認（室内に洗濯機置場がなければコインランドリー or 自宅運用のルール化）
- [ ] 〔中／契約直後〕消毒用アルコール、除菌シート、ペーパーシーツ、ゴミ箱、スリッパ、体組成計
- [ ] 〔中／契約直後〕**姿勢撮影用のタブレット＋三脚**（姿勢分析アプリを使うなら事前に動作確認）
- [ ] 〔低／契約直後〕待機用の椅子、小さめのサイドテーブル、ウォーターサーバー不要（ペットボトル提供で十分＝固定費削減）
- [ ] 〔低／契約直後〕BGM環境（スマホ＋Bluetoothスピーカー。**商用利用可能な音源**を使う。市販の音楽CDやサブスクの個人プランは店内BGMには使えないので注意）
- [ ] 〔低／オープン1週間前〕予備の消耗品を1ヶ月分ストック

## 6. サービス設計（メニュー・料金・規約）

- [ ] 〔高／契約直後〕**メニューと料金を確定**：単発／初回体験／回数券の3本柱。週数日稼働なので**単価を下げすぎない**（客数で稼げないモデルであることを直視する）
- [ ] 〔高／メニュー確定時〕**1枠の所要時間を決める**：施術60分＋前後の準備・記録15分＝75分などの実所要で予約枠を設計する（ここを詰めすぎると当日が破綻する）
- [ ] 〔高／メニュー確定時〕**営業日・時間帯の型を決める**：例）火・木・土の10:00-19:00。予約システムの設計に直結するので先に確定させる
- [ ] 〔高／オープン2週間前〕**利用規約・キャンセルポリシーを作成**：前日まで無料／当日50％／無断キャンセル100％など。予約フォームに同意チェックを置く
- [ ] 〔高／オープン2週間前〕**問診票・同意書のフォーマット作成**：既往歴、痛みの部位、医師の治療中か否か。**医療機関の受診を勧めるべきケースの線引き**を自分の中で明文化しておく
- [ ] 〔中／オープン2週間前〕**プライバシーポリシーを作成**：問診内容・連絡先を扱うため必須。HPに掲載
- [ ] 〔中／メニュー確定時〕**決済手段を確定**：現金＋キャッシュレス。QRコード決済（PayPay等）は導入コストが低い。カード端末は決済額に応じて後から導入で十分
- [ ] 〔中／オープン2週間前〕領収書のフォーマット、売上の記録方法を決定
- [ ] 〔低／オープン前〕**リピート導線の設計**：施術後に次回予約をその場で取る運用フローを決めておく（週数日モデルはリピート率が生命線）

> 詳細な技術設計は `docs/booking-system-roadmap.md` を参照。

- [ ] 〔高／契約直後〕**ドメインを取得**（屋号に合わせる。年1,500円程度）
- [ ] 〔高／契約直後〕**Googleビジネスプロフィールに登録**：名古屋市北区のローカル検索で最も効く無料施策。**登録には住所公開が伴う**ため、オーナー・管理会社の了承と、自身の安全面の判断を先に済ませる
- [ ] 〔高／オープン3週間前〕**HPを公開**（コンセプト／2017年からの実績プロフィール／メニュー・料金／アクセス）：完成を待たず、最小構成で先に公開して検索インデックスを進める
- [ ] 〔高／オープン2週間前〕**予約システムを稼働**：自作が間に合わない場合の**暫定案（LINE公式＋Googleフォーム）を必ず用意**しておく
- [ ] 〔中／契約直後〕**LINE公式アカウントを開設**：無料枠（月200通）で予約リマインドと再来店促進が回る。友だち追加QRを店内とHPに設置

- [ ] 〔中／オープン3週間前〕**撮影**：室内、施術風景（モデル）、プロフィール写真。**HPの信頼感は写真の質でほぼ決まる**。自然光の時間帯に半日確保
- [ ] 〔中／オープン2週間前〕会計ソフト（freee／マネーフォワード）を導入し、口座・カードを連携
- [ ] 〔中／オープン2週間前〕連絡先の電話番号を決定（携帯直通 or 050番号アプリ）
- [ ] 〔低／オープン1週間前〕Googleアナリティクス／Search Console設置
- [ ] 〔低／オープン後〕Googleマップの口コミ依頼カード（QR付き）を作成

## 見落としやすい落とし穴 5選

1. **手洗い・トイレ問題**：バス・キッチンなし物件では洗面台がないことがある。施術業で手指衛生の導線がないのは致命的。内見時に最優先で確認する。
2. **搬入経路**：ベンチプレスは「置ける」より「入らない」で失敗する。エレベーター内寸と階段の踊り場を必ず実測する。
3. **口頭承諾の危うさ**：オーナーが交代・管理会社が変更になった瞬間、口頭合意は消える。必ず書面（覚書・特約）で残す。
4. **青色申告承認申請の期限**：開業から2ヶ月。ここを逃すと初年度の控除を丸ごと失う。開業届と同時に出すのが唯一の正解。
5. **広告表現**：「矯正」「治る」は業種によっては法令抵触リスクがある。HPを作る前に表現ルールを決めておく（後から全ページ直すのは苦痛）。
