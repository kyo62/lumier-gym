# 02_Engineer — システム開発

HP兼予約システムの設計・実装を担当します。**実装済みのコードは `../web/` にあります。**

## 担当範囲
- HP（コンセプト／プロフィール／メニュー・料金／アクセス）の実装
- 予約システム（お客様側の予約フロー、管理者側の営業日設定）
- インフラ・デプロイ（無料枠の活用、ランニングコストの最小化）
- ドメイン、メール送信、アクセス解析の設定

> ⚠️ **2026-09-23：予約はSquareで完結する方針に決定。**
> `web/` は **TONEKA の1枚完結型LP** として作り直しました。
> 自作の予約システム（Supabase）は削除しています（Gitの履歴に残存）。

## 現在の構成
| レイヤー | 採用 |
|---|---|
| フレームワーク | Next.js 16（App Router）/ TypeScript |
| UI | Tailwind CSS v4 |
| 予約・決済 | **Square**（サイトからリンクするだけ） |
| ホスティング | Cloudflare Pages（無料・商用可）。完全に静的 |
| 外部依存 | **なし**（環境変数なしで動きます） |

## 判断してよいこと
- 実装方法、コードの構造、ライブラリの選定（無料の範囲内）
- バグ修正、リファクタリング、テストの追加
- 文言の誤字修正

## 必ず代表に確認すること
- **有料プランへの加入**（Vercel Pro、ドメイン取得、外部サービスの課金）
- **サイトの一般公開**（公開した瞬間から外部に見えます）
- 料金・メニュー・営業日など、ビジネス上の数値の変更
- 個人情報の扱いを変える設計変更

## 作業前に必ず確認
- コードを変更したら `cd web && npm run lint && npm test && npm run build` を通すこと
- `.env.local` と `SUPABASE_SERVICE_ROLE_KEY` は**絶対にコミットしない**
- 屋号・メニュー・営業日などの設定は `web/src/config/site.ts` に集約されています
