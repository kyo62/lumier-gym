# Google Search Console の登録：Claude in Chrome への依頼文

作成：2026-10-21　／　状態：未実施

## 目的
- Googleに、サイト `https://toneka.jp` の存在を知らせる（検索に出るまでの時間を短くする）。
- 方法：「ドメイン」のプロパティで登録し、確認のために、Cloudflare のDNSに、**TXTレコードを1つだけ**追加する。

## 代表が決めること（先に）
- **どのGoogleアカウントで登録するか。** Search Console の所有者は、そのアカウントになります。のちに、Googleビジネスプロフィール（GBP）も同じアカウントで作るのがおすすめ。個人用のGmailと分けたい場合は、サロン用に新しく作ったアカウントにする。
- 代表が自分で行う操作：Googleへのログイン、Cloudflare へのログイン（認証コードを含む）。

## 依頼文
```
Google Search Console に、サロンのサイトを登録する手伝いをしてください。決まりを守ってください。
- ログイン（Google、Cloudflare）、パスワードや認証コードの入力は、私（代表）が自分で行います。その画面が出たら、手を止めて「ここは私が操作してください」と伝えてください。
- 有料の設定、支払いは、しないでください。
- DNSの変更は、次の「TXTレコードを1つ追加する」操作だけにしてください。すでにあるレコード（MX、SPF、DKIM、CNAME など）は、変更・削除しないでください。
- 各手順の最後に、やったことと画面の状況を短く報告してください。迷ったら、止まって私に聞いてください。

手順
1. https://search.google.com/search-console を開く。ログインは私が行います。
2. 「プロパティを追加」で、種類は「ドメイン」を選び、toneka.jp を入力して「続行」を押す。
   （「URLプレフィックス」ではなく「ドメイン」です。）
3. 「ドメインの所有権を確認」の画面に、TXTレコードが表示される（google-site-verification=… で始まる文字列）。その文字列を、そのまま私に見せてください。コピーボタンで、コピーしておいてください。
4. 別のタブで、https://dash.cloudflare.com を開く。ログインは私が行います。
5. ドメイン toneka.jp を選び、「DNS」→「レコード」を開く。
6. 「レコードを追加」で、次のとおりに入力して保存する。
   - タイプ：TXT
   - 名前：@（ルートのドメイン。toneka.jp）
   - コンテンツ：3でコピーした文字列（google-site-verification=… の全体）
   - TTL：自動
   - （プロキシの設定は、TXTには出ません）
   保存したら、DNSのレコード一覧に、TXTが追加されたことを報告してください。ほかのレコードには触れていないことも、報告してください。
7. Search Console のタブに戻り、「確認」を押す。
   - 「所有権を確認しました」と出たら、成功です。
   - 「確認できませんでした」と出たら、数分あけて、もう一度押してください。それでもだめなら、止まって、画面の文面を私に見せてください（DNSの反映に時間がかかることがあります）。
8. 成功したら、左メニューの「サイトマップ」を開き、`sitemap.xml` と入力して「送信」を押す。「成功しました」と出るか、状況を報告してください。（「取得できませんでした」と出ても、少し待ってから再度試すことがあります。その場合は報告だけで、やり直しは私が指示します。）
9. 左メニューの上の検索欄（URL検査）に `https://toneka.jp/` を入れ、結果を報告してください。「URLはGoogleに登録されていません」と出たら、「インデックス登録をリクエスト」を押してください（数分かかることがあります）。
10. 最後に、やったことの一覧と、残っている作業を報告してください。
```

## 終わったあとに
- 検索に出るまでには、数日〜数週間かかることがある（私の理解。時間は断定できない）。
- 1〜2週間後に、Search Console の「ページ」の画面で、登録されたページ数を確認する。
- 追加したTXTレコードは、**削除しないでください**（消すと、所有権が外れることがある）。
