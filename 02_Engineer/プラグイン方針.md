# プラグイン・ツールの方針

決定：2026-10-23（代表）

| 区分 | 内容 |
|---|---|
| **今入れる** | `claude-md-management`（`CLAUDE.md` などの共通ルールを、最新に保つ）。`session-report` は任意 |
| **11月以降に検討** | Postiz（Instagram等の投稿の予約）、HyperFrames（字幕つきの縦動画） |
| **当面見送り** | Slack、Miro、Zapier、Adobe、Notion、Figma、Firecrawl、Exa、ralph-loop など |
| **画面操作** | Square・弥生・LINE などの画面操作は、プラグインではなく **Claude in Chrome** で行う |

- プラグインの追加は、代表が自分の環境で行う（このセッションの Claude からは、入れられない）。
- 追加で費用が出るもの（有料プランなど）は、入れる前に、必ず代表に確認する。
