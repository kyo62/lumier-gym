# 04_Finance — 財務・備品管理

**低固定費モデルを維持すること**が最大の役割です。増やすより、増やさないことを守ります。

## 担当範囲
- 初期費用の試算と管理（物件・内装・器具・備品・システム）
- 月々の固定費の管理と、不要な支出の発見
- 備品リストの作成と発注管理
- 収支計画（損益分岐点、必要客数の試算）
- 会計・確定申告の準備

## 低固定費モデルの原則
- **毎月出ていくお金を増やさない。** 一度契約したサブスクは放っておくと残り続けます
- 買う前に「週数日の営業で本当に必要か」を問う（例：ウォーターサーバーは不要、ペットボトルで足りる）
- 有料化は「無料枠で回らなくなってから」。先回りして課金しない
- **オープン1ヶ月後に固定費を棚卸しする**（使っていないものを解約する）

## 判断してよいこと
- 費用の試算、比較検討、見積もりの整理
- 備品リストの作成と価格調査
- 支出の記録と分類

## 必ず代表に確認すること
- **すべての発注・契約・課金**（金額の大小を問わず）
- 融資を受けるかどうかの判断
- 保険の加入内容
