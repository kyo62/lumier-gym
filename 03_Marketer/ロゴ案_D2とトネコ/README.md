## 見た目（読み込んで確認した内容）
- **シンボル：** 両腕を広げて深呼吸する人の形。左がゴールド、右がチャコールの、しなやかな2本の曲線。頭は、ゴールドの丸（気泡の色）。
- **文字：** 「TONEKA」は Cinzel（ローマ字の大文字・セリフ）、「PERSONAL CONDITIONING」は Zen Kaku Gothic New。
- **トネコ：** 三毛猫。目を閉じ、しっぽをピンと上げ、水彩風のやわらかい線。**水平器は持っていない**。

## 私が見つけた点（HPに入れる前に、決めたい）
1. **フォントの食い違い：** HPのロゴ文字は Jost（ゴシック）ですが、D-2ロゴの「TONEKA」は Cinzel（セリフ）です。HPのヘッダーにD-2ロゴを入れるなら、HP全体のロゴ文字も、そろえるか、シンボルだけを使うか、決めたい。
2. **小さいサイズ：** シンボルは、32px程度までは読めるが、16pxのファビコンでは、腕の細い線が弱くなる。ファビコン用には、線を太くした簡略版を別に作るのがよい（作れる）。
3. **元のコードの仕組み：** 元のSVGは、外部フォントの読み込みに頼っていたため、画像として使うと文字の形が変わる。ここでは、文字を図形に直した（解決済み）。トネコの「水彩のゆらぎ」は、SVGのフィルターで、見た目は同じだが、少し処理が重い。ページ内に大きく何枚も置くのは避けたい。
4. **色：** トネコは、オレンジ・茶・ピンクを使っている。サロンの色（クリーム・ゴールド・チャコール）とは別だが、キャラクターとして自然な範囲。
5. **三つのマーク：** 水平器（これまで）、Tロゴ4案（[`../ロゴ案_Tとトネコ/`](../ロゴ案_Tとトネコ/README.md)）、D-2ロゴ。**どれを正式にするか**（使い分けるか）を決めたい。
