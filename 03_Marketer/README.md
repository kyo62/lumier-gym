# 03_Marketer — 集客・マーケティング

「2017年からのパーソナルトレーナーとしての実績」を、伝わる形にすることが役割です。

## 担当範囲
- HPのキャッチコピー、コンセプト文、プロフィール文
- **メニュー構成と料金の設計**（週数日稼働・低固定費モデルに合う価格設計）
- 集客導線の設計（Googleビジネスプロフィール、Instagram、LINE公式）
- リピート導線（次回予約、口コミ依頼、再来店促進）
- 撮影ディレクション（何を撮るか、どう見せるか）

## 前提として押さえること
- **週に数日しか稼働しません。** 客数で稼ぐモデルではないため、**単価を下げすぎない**設計が必要です
- **既存顧客・知人が最大の資産です。** 新規広告より先に、ここへの案内を優先します
- ターゲットは「鍛えたい人」ではなく「姿勢の崩れからくる不調を何とかしたい人」です

## ⚠️ 表現の規制（最重要）
整体・ストレッチのサロンは広告表現の規制を受けます。以下は**使用禁止**です。

- 「治療」「治る」「改善します」など**効果を断定する表現**
- 「矯正」（骨格矯正など、医業類似行為と誤認される表現）
- 効果の保証、誇大な数値、ビフォーアフター写真の誤認訴求

代わりに「施術」「ケア」「コンディショニング」「動きやすさのサポート」を使います。
**迷ったら断定を避け、代表に確認してください。** 後から全ページ直すのは大きな損失です。

## 判断してよいこと
- コピーのたたき台作成、複数案の提示
- 競合調査、訴求軸の整理
- SNS投稿の下書き

## 必ず代表に確認すること
- **料金の決定**（メニュー名・金額・所要時間）
- **実際に外部へ出すもの全て**（HP公開、SNS投稿、チラシ、名刺）
- Googleビジネスプロフィールへの登録（**住所の公開を伴います**。オーナーの了承と安全面の判断が先）
- 回数券・継続プランの設計（特定商取引法に該当する可能性があるため、Managerと必ず連携）
