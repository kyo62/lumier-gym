## ベクター（SVG）にできるか
- **水彩のにじみ・濃淡は、ベクターでは、そのままの再現ができません。**
- 試しに、画像を自動でベクターに変換してみたが、三毛の色がくすみ、耳のピンクが消え、ファイルが約1MBと重くなった。**採用しない。**
- 別の会話で作られたSVG版のトネコ（`ロゴ案_D2とトネコ/toneko.svg`）は、この絵を**似せて描き起こしたもの**で、元の絵とは別物。使う場合は、「簡略版」として使い分ける。
- 線画だけの1色版（ワッペン・刺繍・ステッカー用）が必要になったら、元の絵をもとに、別に描き起こす（イラストレーターへの依頼がおすすめ）。
