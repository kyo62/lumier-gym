## 意見

### ① 2アカウント構造は正しい

店舗アカウントは「場所」を売り、個人アカウントは「人」を売る。買う理由が違うので、混ぜると両方ぼやける。
分ける判断は妥当で、ここは変えなくていい。

### ② ただし、個人アカウントには構造的な矛盾がある

HYROX・ウェイトトレーニング・バスケ・ランニングの発信は、**フォロワーが男性中心になる。**
しかし TONEKA は**男性の新規を受けていない**（紹介のみ／`00_Context/salon_info.md`）。

つまり個人アカウントは、集客チャネルとしては効率が構造的に悪い。断る問い合わせが増える可能性がある。

> **【2026-09-28 追記】この指摘は、代表の「女性ランナー向け」案で解消されました。**
> 下の「個人アカウントの再定義」を参照。以下は、その前提となった当初の整理です。

**だから止めろ、とは言いません。** 位置づけを変えるべきだと考えます。

- ❌ 集客チャネル（個人アカウント → TONEKA 予約）
- ⭕️ **信頼の裏付け ＋ 紹介の入口**

「自分でも競技をやっていて、そのために自分の身体を整えている人」という事実は、
施術者としての説得力を最も強く担保します。これは店舗アカウントでは出せません。

そのうえで狙うのは、**男性フォロワー本人ではなく、その人からの紹介**（妻・母・同僚・チームメイト）。
サロンが紹介制である以上、これが最も噛み合います。

### ③ 媒体は絞る。順番をつける

「使えるだけ回す」は、開業前の3ヶ月で最も潰れやすい方針です。
いま代表が持っている最も希少な資源は、お金ではなく**時間**です。

**推奨する順番：**

| 段階 | やること | 理由 |
|---|---|---|
| **今すぐ（10月）** | Instagram（TONEKA）を開設し、撮影を始める | ターゲット年代との重なりが最大 |
| **11月** | **Googleビジネスプロフィール申請**（`next_actions.md` に記載済み） | 無料かつ地域集客の本丸。オーナー確認に日数がかかる |
| 同時 | Instagram（個人） | すでにアカウントがあるなら流用でよい |
| リールが溜まってから | TikTok / YouTube Shorts に**同じ動画を転載** | 新規制作しない。転載だけなら追加コストはほぼゼロ |
| ついで | Threads | Instagramから流せる範囲だけ |
| **やらない（当面）** | **X** | 拡散力はあるが、40〜60代女性の地域サロン集客とは噛み合わない |

X をやらない判断は、あとから覆せます。**先にやらない理由がある側を止める**のが、1人運用の鉄則です。

### ④ Googleビジネスプロフィールが最優先である理由

「名城公園 整体」「名城公園 パーソナル」で探す人は、**すでに行く気がある人**です。
SNSで認知を広げるより、ここに出る方が予約への距離が圧倒的に短い。しかも無料。

**ただし注意点が3つあります。**

1. **登録に時間がかかる。** オーナー確認（ハガキ・電話・動画などの方法がある）に日数を要する。
   12月プレオープンに間に合わせるなら、**11月中には申請**が必要。
   `next_actions.md` の11月タスクに記載済みなので、時期の設定は既に正しい。
2. **住所が公開される。** 完全予約制・1対1・女性中心のサロンなので、飛び込み客の想定が要ります。
   → **代表の判断が必要**（下記）。
3. **口コミがそのまま資産になる。** 11月のプレプレオープンのモニターに、
   感想をGoogleにも書いてもらえるよう依頼しておくと、12月時点で口コミがゼロになりません。

### ⑤ リールの表現には、明確な地雷がある

「今日の1エクササイズ」は、**このジャンルで最も表現が滑りやすい形式**です。
不調を抱えた人に向けた動画なので、効果を断定した瞬間に広告規制に触れます（`CLAUDE.md` 第4項）。

| 使わない | 代わりに使う |
|---|---|
| 肩こりが治る／改善します | 肩まわりが動かしやすくなる |
| 腰痛が治る | 腰まわりをゆるめる |
| 骨盤矯正 | 骨盤まわりのコンディショニング |
| 姿勢が治る | 姿勢が整いやすくなる |
| 〇〇に効く | 〇〇のときに試してほしい |

**動画には毎回この一文を入れる：**

> 痛みのある方、通院中・治療中の方は、医療機関にご相談のうえ行ってください。

これは法令対策であると同時に、**自宅で真似した人の事故から自分を守るため**でもあります。

### ⑥ 撮影は10月1日から始める。投稿は後でいい

**これが今回いちばん実務的に重要な指摘です。**

10月1日に鍵を受け取ります。そこから内装が入り、什器が届き、看板がつく。
**この「作っている過程」は、開業後には二度と撮れません。**

- 何もない空の部屋
- 施術ベッドが初めて入った日
- 看板がついた瞬間
- ドリンクの試作、備品を選んでいるところ

開業してから「素材がない」と気づくのが、開業前アカウントで最もよくある失敗です。
**投稿しなくていいので、10月1日から撮ってフォルダに溜める。** これだけは今日決めてよいと思います。

また、フォロワーはゼロから育つのに時間がかかります。1月に開けてから始めるのでは遅い。

### ⑦ 続ける仕組みを、内容より先に決める

毎日投稿は続きません。1人で施術もする以上、破綻します。

- **週1回のまとめ撮り**で5〜8本つくる
- 撮影日をカレンダーに固定する（例：毎週月曜の午前）
- ハイライトは開業時点で空になる。**埋まる順番を決めておく**
  （①アクセス ②料金 ③セッションの流れ ④お客様の声 ⑤よくある質問）

「何を投稿するか」より「いつ撮るか」を先に決める方が、続く確率が上がります。

媒体ごとに作り分けはしない。YouTubeの横長・長尺はたまに、ゆるやかに。

10月1日以降に住所が確定するので、そこで登録して地図に出す。口コミも集める。

## 個人アカウントの再定義：女性ランナー向け（2026-09-28・代表の発案）

### これで、前に指摘した矛盾が解けます

Claudeは当初「個人アカウントは男性フォロワーが集まるので、男性の新規を受けないサロンとは噛み合わない」と指摘しました。
**代表の提案（名古屋ウィメンズマラソンに向けた女性ランナー向けコンディショニング）は、この矛盾を構造から解消します。**

理由：

| | |
|---|---|
| **大会が女性限定** | 名古屋ウィメンズマラソンは女性限定の大会。関心層がそのまま女性に寄る |
| **年齢が合う** | 市民ランナーの中心層とサロンのターゲット（30〜50代女性）が重なる |
| **立地が合う** | スタート・フィニッシュはバンテリンドーム ナゴヤ。名城公園から近い |
| **悩みが具体的** | 「痛みなく走り切りたい」は、漠然とした不調より言語化されている |
| **締切がある** | 大会日が決まっているので、行動の期限が向こう側にある |

### 時期が、偶然とは思えないくらい噛み合っています

| 時期 | 出来事 |
|---|---|
| 2026年10月 | 物件の鍵を受領・準備月／**タキシード隊2027の募集（推定）** |
| 2027年1月 | TONEKA グランドオープン |
| **2027年3月14日（日）** | **名古屋ウィメンズマラソン2027** |

**オープンから大会まで、およそ2ヶ月。** ランナーにとっては最終調整の時期です。
しかも一般エントリーは例年もっと早い時期に締まるため、**3月に走る人は、その頃にはもう決まっています。**
「これから申し込む人」ではなく「**走ることが決まっていて、不安を抱えている人**」に向けられます。

出典：
- 開催日・会場：https://womens-marathon.nagoya/
- https://prtimes.jp/main/html/rd/p/000000323.000022390.html

※ コースが名城公園を通るかどうかは**未確認**。公式のコース図で確認すること。

### 発信の「順番」を逆にする

当初案は「運動記録がメイン、合間にコンディショニング」でした。**これを逆にします。**

| | 当初案 | 変更案 |
|---|---|---|
| 主 | 運動記録（HYROX・ウェイト・バスケ・ラン） | **走るためのコンディショニング** |
| 従 | 合間にコンディショニング | 運動記録＝**「なぜそれをやるか」の裏付け** |

記録をただ載せると、受け取る側は「すごい人」で終わります。
**順番を変えると、同じ素材が「この人に見てもらいたい」に変わります。**

> 例：HYROXのウォールボールの動画 → 次に「これをやるために、自分は肩をこう整えている」

競技が全部「走る」に繋がっていることも、説得力として効きます。

### 掲げる目標は、タイムではない

代表の言うとおり、**「タイムを縮める」ではなく「痛みなく走り切る」**を掲げるべきです。

これは TONEKA のコアメッセージ「**がんばる前に、まず整える**」と、まったく同じことを言っています。
サロン本体とランナー向けが、別々のことを言わずに済みます。ここがこの案の一番強いところです。

### ただし、サロンの業態を変えないこと

**ランナー向けは「入口のひとつ」であって「業態」ではありません。**
当たったときほど、「ランナー専門店」に見え始めないか注意してください。
本体は30〜50代女性の姿勢とコンディショニングです（`00_Context/salon_info.md`）。

## 転載を「本当にゼロコスト」にするための4つの設定

転載そのものは無料ですが、**やり方を間違えると無料どころかマイナスになります。**
以下は最初に1回決めれば、あとは永久に効く設定です。

### ① 書き出しに、他アプリの透かしを入れない

**TikTokで書き出した動画（右下にTikTokのロゴが入る）をそのままInstagramに上げると、リーチが制限されます。**
Instagramは他アプリの透かしが入った再利用コンテンツを、リール面で表示しにくくしていると説明しています。

**対策：** 編集はアプリの外（CapCut等、透かしオフで書き出す）で行い、
**できた素の動画ファイルを各アプリに個別にアップする。** アプリからアプリへ持ち回さない。

参考：https://www.comnico.jp/we-love-social/ig-algorithm

### ② 音源は、最初から商用利用可のものにする

Instagram の音源ライブラリにある楽曲は、**ダウンロードすると音が消えるか、権利の関係で他媒体に出せません。**
またビジネスアカウントでは使える楽曲が制限されます。

**対策：** 最初から
- 商用利用可のフリー音源（YouTube オーディオライブラリ等）
- または **無音＋ナレーション＋字幕**

にしておく。字幕中心の方が、音を出さずに見る人（電車・職場）にも届きます。
**ターゲットが40〜60代なので、字幕は必須と考えてよいです。**

### ③ テロップは、画面の上下に寄せない

各アプリで、ボタンやキャプションが重なる位置が違います。
**上下それぞれ15%程度を空け、文字は中央寄りに置く。** これで全媒体で読めます。

### ④ 尺は Instagram リールに合わせる

Instagram リールの上限に収めておけば、TikTok にも YouTube ショートにも通ります。
逆（TikTokの長尺基準）で作ると転載できません。**一番短い基準に合わせるのが鉄則。**

### 導線

TikTok・YouTube・Threads の各プロフィールに、**Instagram と HP のリンクを置く。**
着地はすべて Instagram に集める。

## Googleビジネスプロフィール：順番を間違えるとアカウントが止まる

**⚠️ これが今回いちばん重要な注意点です。**

### 事実

- 開業前でも登録でき、**開業予定日を設定できる**
  出典（Google公式）：https://support.google.com/business/answer/9174409?hl=ja
- オーナー確認の方法は、ハガキ・電話・メール。**動画の提出を求められる場合がある**
- **オーナー確認が済んだ「あと」に未来の開業日を入力すると、プロフィールが公開停止になる場合がある**
  → 複数の民間情報源が一致して警告している。**ただしGoogle公式ヘルプに明記された記述は確認できていない（未確認）**
  https://locaop.jp/media/meo/opening-date_important-point/

### 正しい順番

1. プロフィールを作成する
2. **先に開業予定日（2027年1月◯日）を入力する**
3. **そのあとで**オーナー確認に進む

**逆順にしない。** リスクを避ける順番で進めれば、どちらにしても損はありません。

### 動画確認への備え

動画での確認を求められた場合、**外観や看板を撮るよう指示されることがあります。**
看板がつく前に確認に進むと通らない可能性があるため、

> **看板の設置 → オーナー確認**

### 論点1：媒体をどこまで絞るか　→ **決着：全部使う（1本を転載）**

| 案 | 内容 | メリット | デメリット |

### 論点2：Googleビジネスプロフィールで住所をどう出すか　→ **決着：公開する**

| 案 | 内容 | メリット | デメリット |
|---|---|---|---|
