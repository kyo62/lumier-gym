# 初回体験のメッセージ文例（たたき台）

作成：2026-10-05
担当：03_Marketer

> **外に出る文章です。** 代表が読んで、自分の言葉に直してから使ってください。
> `【 】` の中は、状況に合わせて入れ替えます。
> 表現のルール（`CLAUDE.md` 第4項）に合わせ、「治療」「矯正」「改善します」などは使っていません。

## 初回体験の全体の流れ（2026-10-05 代表の決定）

1. お客様が、**LINE・電話・メールのどれか**から連絡する。
2. 代表が、**最初の返信**（文例A）で、必要な情報をお願いする。
3. 「電話を希望するか」を選んでもらう。希望する方には、**電話できる日時の候補**を送る（文例B）。
4. 男性の場合は、**ご紹介者**を確認する（文例C）。
5. 日時を決めて、**確定のご案内**（文例D）を送る。体験料は**当日払い**（事前決済なし）。
6. **前日にリマインド**（文例E）。
7. 当日。体験のあと、次の予約や、会員の案内をする。

---

## A. 最初の返信（LINE・メール共通）

```
【お名前】さま

TONEKA（トネカ）にご連絡いただき、ありがとうございます。
初回体験のお申し込みですね。

スムーズにご案内するため、次のことを教えていただけますか。

・お名前
・ご性別
・メールアドレス
・お電話番号
・ご来店の目的（TONEKAでセッションを受けたい理由、お悩みなど）
・（男性のお客様）ご紹介者さまのお名前

いただいた情報は、ご案内とセッションの準備のためにのみ使用します。
なお、病名や通院歴など、医療に関わる内容は、お書きいただかなくて大丈夫です。

【お電話のご案内について】
当日のアクセスなどを、お電話で詳しくご案内することもできます。

　□ 電話でのご案内を希望します
　□ 希望しません（メッセージでのご案内で大丈夫です）

どちらかを、お知らせください。

TONEKA　伊藤
```

## B. 「電話を希望する」と返信が来たとき

```
ご返信ありがとうございます。
お電話の日時を、次の中からお選びいただけますか。

　1.【月日（曜日）　時〜時】
　2.【月日（曜日）　時〜時】
　3.【月日（曜日）　時〜時】

ご希望の時間に、こちらからお電話します。
（お電話は、070-【番号】からかけます。）
上のどれも難しい場合は、ご都合のよい日時をお知らせください。
```

> メモ：070からの着信は、出てもらえないことがあるため、**電話の直前にLINEやSMSで「いまからお電話します」と一言入れる**と、出てもらいやすくなる（私の提案）。

## C. 男性のお客様のとき（ご紹介の確認）

**ご紹介者がいる場合：**

```
ご連絡ありがとうございます。
男性のお客様は、TONEKAをご利用中の方からのご紹介制にしております。
ご紹介者さまのお名前を、教えていただけますか。
```

**ご紹介がない場合（お断りではなく、ご紹介制の案内として）：**

```
ご連絡いただき、ありがとうございます。
男性のお客様のご利用は、現在、ご利用中の方からのご紹介に限らせていただいております。
ご紹介をいただける方がいらっしゃいましたら、あらためてご連絡ください。
お気持ちに添えず、申し訳ありません。
```

> 「お断り」ではなく「ご紹介制」と伝える（`会員規約_追加条項ドラフト.md` の表現と同じ）。

## D. 日時の確定のご案内（体験料は当日払い）

```
【お名前】さま

ご予約を承りました。

■日時：【月日（曜日）　時〜時】
　（施術は60分です。前後のお着替え・おくつろぎの時間と、準備のための時間をあけるため、
　　90分の枠をお取りしています）
■内容：初回体験
■体験料：【金額】円（当日、店頭でのお支払いです）
■お持ちいただくもの：動きやすい服装（更衣スペースがあり、お着替えもいただけます）
■アクセス：地下鉄名城線「名城公園」駅から徒歩すぐ
　（詳しい住所と、お車の場合のパーキングは、別のメッセージでお送りします）

【キャンセル・日時の変更について】
ご予約日の前日23:59までに、LINEまたはお電話でご連絡ください。
当日のキャンセルは、体験料の全額をいただきます。
（災害など、やむを得ない場合は除きます）

当日、お会いできるのを楽しみにしています。
TONEKA　伊藤
```

> メモ：キャンセル料の書き方は、公開前に、名古屋市消費生活センターなどで確認する（`会員規約_追加条項ドラフト.md` を参照）。

## E. 前日のリマインド

```
【お名前】さま

明日【時】からの初回体験のご案内です。
お気をつけてお越しください。

・お持ちいただくもの：動きやすい服装（お着替えもできます）
・お車の場合：【パーキングのご案内】
・ご到着が遅れそうなときは、お電話かLINEでご連絡ください

お会いできるのを楽しみにしています。
TONEKA　伊藤
```

## F. 電話のときの流れ（当日のアクセスなどの案内）

1. **名乗る：**「TONEKAの伊藤です。【お名前】さまのお電話でよろしいでしょうか。いま、少しお時間よろしいですか。」
2. **お礼：**「ご連絡いただき、ありがとうございます。」
3. **聞くこと：**
   - お車でお越しですか？（パーキングの案内に使う）
   - 当日、気になっていること、お悩みを、簡単に教えてください（くわしくは、当日うかがいます）
   - 動きやすい服装の準備は、大丈夫そうですか
4. **伝えること：**
   - 当日の流れ（お着替え → カウンセリング → 調整 → 連動チェック → 振り返り）
   - 施術は60分、枠は90分（ゆっくりしていただけます）
   - 体験料は当日払い
   - キャンセルは前日23:59まで
5. **終わり：**「このあと、メールで、住所とパーキングの情報をお送りします。当日、お会いできるのを楽しみにしています。」

> メモ：ご紹介制の確認が目的の電話ではなく、**不安を減らし、楽しみを増やすための電話**にする（代表の考え）。

## G. キャンセルの連絡を受けたとき

**前日23:59までに連絡があった場合：**

```
ご連絡ありがとうございます。キャンセルを承りました。
またご都合のよいときに、ご連絡ください。
```

**当日のキャンセル（体験）：**

```
ご連絡ありがとうございます。キャンセルを承りました。
当日のキャンセルのため、体験料【金額】円を、次回のご来店時にいただきます。
（ご案内のとおりです。ご了承ください）
またご都合のよいときに、ご連絡ください。
```

**当日のキャンセル（会員）：**

```
ご連絡ありがとうございます。キャンセルを承りました。
当日のキャンセルのため、キャンセル料1,000円を、次回のご来店時にいただきます。
（プランの回数は、消化されません）
お大事になさってください。振替のご希望日を、お知らせください。
```

> 災害・身内の不幸、または感染症で行政の注意喚起がある期間は、キャンセル料なし。
