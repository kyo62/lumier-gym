## 1. 訴求の言い方（代表案・そのまま使える）

代表の言い回しは、**広告表現として安全な型になっています。**

> 痛みなく走れるようになりたい方へ
> できるだけ痛みを少なくしたい方へ
> タイムより「完走」を目標にしたい方へ

**なぜ安全か：主語がお客様側にあるからです。**
「〜できます」は自分（提供者）が効果を約束する形ですが、「〜したい方へ」は**誰に向けた場所かを述べているだけ**で、効果を断定していません。

### 使い回せる型

| 型 | 例 |
|---|---|
| **〜したい方へ** | 痛みなく走り切りたい方へ |
| **〜な方から相談が増えています** | 膝まわりが気になる、という方からの相談が増えています |
| **〜のお手伝いをします** | 完走に向けて、身体を整えるお手伝いをします |
| **一緒に〜しませんか** | 走る前に、少しだけ整えていきませんか |

**避ける型：** 「治ります」「改善します」「完走できます」「記録が伸びます」「故障を防ぎます」
（`CLAUDE.md` 第4項）

## 2. ⚠️ 大会1週間前のイベントには、落とし穴があります

### 事実

マラソン大会の直前1〜2週間は**テーパリング（調整期）**と呼ばれ、練習量を落として疲労を抜く期間です。
スポーツの現場では「**大会直前に、やったことのないことをしない**」が広く共有された原則です。

### だから何が問題か

**「1週間前から受け付けます」を、初めての人に開くと危ない。**

初めて受ける施術は、身体にとって新しい刺激です。
それを大会の数日前に入れると、当日に違和感が出る可能性があります。
そうなったとき、**お客様は「あの施術のせいだ」と考えます。** 因果が証明できなくても、その印象は残ります。

**開業直後のサロンにとって、これは最も避けたい事故です。**

### 解決策：やめるのではなく、設計を変える

| | |
|---|---|
| ❌ 「1週間前から受け付けます」だけを打つ | 初めての人が直前に来てしまう |
| ⭕️ **直前週は「仕上げ」だけ。初めての方は2週間以上前に** | 誠実であり、かつ**予約が前倒しになる** |

直前週のメニューは**内容を軽くする**。
ゆるめる・呼吸・可動域の確認まで。強い刺激や、やったことのない動きは入れない。

**これは商売としても正しいです。** 「初めてなら早めに」と案内することで、
**1週間前に集中するはずだった予約が、1〜2ヶ月前に分散します。** 直前だけ忙しくなる事態も防げます。

## 3. 時期の設計：4つの山がある

**「大会1週間前」だけを見ると、3つの山を逃します。**

| 時期 | 何が起きているか | 打つもの |
|---|---|---|
| **1月**（オープン直後） | まだ余裕がある。試せる時期 | **オープン記念。ここで初めてのランナーを取る** |
| **2月**（走り込み期） | **距離が伸びて、故障が最も出る時期。本命** | 「いま痛みが出やすい時期です」 |
| **3月7〜13日**（直前週） | テーパリング。不安がピーク | **仕上げのみ・短時間。既存の方中心** |
| **3月15日〜**（大会後） | **脚が痛い。そして目標を失う** | **いちばんの盲点。下記** |

### 大会後（3月15日〜）が最大の盲点です

走り終わった人は、**ほぼ全員が脚に不調を抱えています。** しかも急いでいません。
さらに「終わってしまった」という空白の時期でもあります。

ここで **「お疲れさまでした。整えてから、次へ」** と声をかけられると、
**単発の来店ではなく、継続に繋がります。**

直前だけのイベントにすると、この山をまるごと逃します。
**大会翌週こそ、一番丁寧に案内すべきです。**

## 4. 「走る前に少しだけストレッチ」= 短時間メニューをどうするか

名城公園にはランニングコースがあり、走っている人が店の前を通る立地です。
「走る前に少しだけ整えていきませんか」は、この立地でしか言えない言葉です。

### ただし、常設にすると本体を食います

| リスク | 内容 |
|---|---|
| **カニバリゼーション** | 安い短時間メニューを常設すると、月額プラン（月4回30,800円）の検討者が安い方へ流れる |
| **運営の負担** | 1対1・完全予約制で短時間枠を挟むと、準備と片付けの回数だけが増える |
| **時間帯** | 「走る前」は朝。朝枠を開けることになる |

### 推奨：常設にしない。期間限定にする

**大会の前後（2月〜3月）の期間限定イベントとして出す。**

- 常設しないので、本体プランを食わない
- 期間限定なので、来る理由が生まれる
- 終わったあと「好評だったので、また」と繰り返せる

**イベントは、試作を安く試せる場です。** 常設メニューにするかどうかは、やってみてから決めればいい。

## 5. イベント設計のたたき台

> **これはたたき台です。価格・時間は代表が決めてください。**

| | 内容 |
|---|---|
| 時期 | 2027年2月〜3月（大会前後） |
| 対象 | 3月の大会に出る方／走っている方 |
| 内容 | 短時間のコンディショニング（呼吸・股関節まわり・肩まわり） |
| 直前週の扱い | **仕上げのみ。初めての方は2週間以上前にご案内** |
| 大会後 | **翌週から「お疲れさまケア」として継続** |
| 告知 | 個人アカウント主体。TONEKAアカウントでも触れる |

### 決めるべきこと

- [ ] 時間と価格（本体プランと competing しない水準に）

- [ ] **回数券・継続契約にするか**

      単発なら該当しません。→ [`会員規約_追加条項ドラフト.md`](../01_Manager/会員規約_追加条項ドラフト.md)

## 6. 表現で越えてはいけない線（再掲）

- **大会名をメニュー名にしない。** 「3月の大会に向けて」と事実で触れる
- **タキシード隊を肩書きにしない。** その年の出来事として書く
- **効果を断定しない。** 「完走できます」「故障を防ぎます」は使わない
