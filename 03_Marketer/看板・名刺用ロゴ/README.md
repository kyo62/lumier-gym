# 看板・名刺用ロゴ（横長）

作成：2026-10-25　／　状態：**代表の確認待ち**（看板・名刺にも使える、横長のロゴ）

## 組み合わせ（正式ロゴ D-2 の、シンボル＋文字）
| 配置 | 内容 | 比率 |
|---|---|---|
| **A：ロゴの下に文字** | シンボルの下に「TONEKA」「パーソナルコンディショニングサロン」 | 5:2（2500×1000） |
| **A＋ひとこと** | 上に、「がんばる前に、まず整える。」を足したもの | 5:2 |
| **B：左にロゴ、右に文字** | 左にシンボル、右に「TONEKA」「パーソナルコンディショニングサロン」 | 3:1（3000×1000） |
| **B＋ひとこと** | 右の文字の下に、「がんばる前に、まず整える。」を足したもの | 3:1 |

- **色：** 明るい（クリーム地）／暗い（チャコール地）の2種類。A・B（ひとこと無し）は、**背景透明**の版もある。
- **形式：** PNG（見る・共有）と SVG（印刷用の元データ。文字は、すべて図形に直してある）。
- **書体：** 「TONEKA」はCinzel、「パーソナルコンディショニングサロン」はZen Kaku Gothic New、ひとことはShippori Mincho（HPの見出しと同じ明朝体）。
- ひとことは、名刺では小さくなるので、**名刺には「ひとこと無し」**、看板・チラシには「ひとこと有り」と使い分けるのも、ひとつの方法。

## 未決（代表）
- 配置は、A・Bのどちらにするか（用途で使い分ける案もある：看板＝B、名刺＝A、など）。
- ひとこと「がんばる前に、まず整える。」を入れるか。
- 「トネカ」（カタカナ）を、小さく足すか。
- 看板・名刺の**実際の寸法・素材・色**（印刷会社に出すときに決める。表札は、管理会社の許可・規定の大きさが先 → [`../../01_Manager/管理会社_看板表札のお願い文案.md`](../../01_Manager/管理会社_看板表札のお願い文案.md)）。
