# サイトの文言を自分で直す

> **結論：`src/config/site.ts` の1ファイルを直せば、サイトの文章はほぼ全部変わります。**
> コードの書き方を知らなくても直せるように作ってあります。

---

## まず、3つのやり方があります

| やり方 | 準備 | 向いている人 |
|---|---|---|
| **A. GitHubのブラウザで直す** | **なし** | まず1文字だけ直したい。パソコンに何も入れたくない |
| **B. パソコンで直す（おすすめ）** | 30分 | **直した結果をその場で見ながら進めたい** |
| **C. Claude Codeに頼む** | Bと同じ | 「ここをこうして」と言葉で伝えたい |

---

## A. GitHubのブラウザで直す（準備なし）

1. https://github.com/kyo62/lumier-gym を開く
2. ブランチを `claude/posture-salon-launch-rxlgl5` に切り替える
3. `web` → `src` → `config` → `site.ts` を開く
4. 右上の**鉛筆マーク**をクリック
5. 直したい文字を書き換える
6. 下の **Commit changes** を押す

**これだけで保存されます。** ただし**直した結果はその場では見られません。** 見た目を確認したいときは、私に「ビルドし直して」と言ってください。

---

## B. パソコンで直す（おすすめ）

**保存した瞬間にブラウザの表示が変わります。** 文章を練るときはこれが一番速いです。

### 最初の1回だけ：準備

1. **Node.js** を入れる → https://nodejs.org （LTS版のボタンを押すだけ）
2. **VSCode** を入れる → https://code.visualstudio.com
3. VSCodeを開いて、上のメニューの「ターミナル」→「新しいターミナル」
4. 次の4行を1行ずつ貼り付けて Enter

```bash
git clone https://github.com/kyo62/lumier-gym.git
cd lumier-gym/web
git checkout claude/posture-salon-launch-rxlgl5
npm install
```

### 毎回：編集する

```bash
npm run dev
```

ブラウザで **http://localhost:3000** を開くと、サイトが表示されます。

**`web/src/config/site.ts` を開いて書き換えて保存すると、ブラウザが自動で更新されます。**

終わるときはターミナルで `Ctrl + C`。

### 直したものを保存する

```bash
git add -A
git commit -m "文言を修正"
git push
```

## どこに何が書いてあるか

`src/config/site.ts` を開くと、上から順にこうなっています。

| 見出し | 直せるもの |
|---|---|
| `site` | 屋号、キャッチコピー、住所、メール、営業日の表示、Instagram |
| `brand` | 屋号の由来（TONE × 家） |
| `sections` | **各セクションの見出しと説明文** |
| `profile` | プロフィールの文章、指導歴、写真のパス |
| `concerns` | 「こんな方に向いています」の5項目 |
| `reasons` | 選ばれている3つの理由 |
| `flow` | セッションの流れ（90分の各ステップ） |
| `monthlyPlans` / `singlePlans` | **料金プラン** |
| `booking` | **Squareの予約URL**、繰り越し・振替の説明、キャンセル規定 |
| `policies` | 「ご利用にあたって」の3項目 |
| `faqs` | よくあるご質問 |
| `businessHours` | 営業曜日・時間 |

## 書き換えの例

### 例1：キャッチコピーを変える

```ts
hero: {
  headline: ['がんばる前に、', 'まず整える。'],
  headlineAccent: '整える',
```

↓ こう変えると

```ts
hero: {
  headline: ['無理をする前に、', 'まず ととのえる。'],
  headlineAccent: 'ととのえる',
```

`headlineAccent` に書いた文字だけ**金色**になります。
（`headline` の中に無い文字を書くと、色は変わらず普通に表示されます）

### 例2：料金を変える

```ts
{
  id: 'monthly4',
  name: '月4回 定期コンディショニング',
  price: 30800,          ← ここの数字を変えるだけ
  unit: '/ 月',
  note: '1回あたり 7,700円',   ← ここも忘れずに直す
```

### 例3：Squareの予約URLを入れる（予約ボタンが有効になります）

```ts
export const booking = {
  squareUrl: '',          ← ここに ' ' の間にURLを貼る
```

↓

```ts
  squareUrl: 'https://square.site/book/XXXXXXXX/toneka',
```

**これだけで、サイト中の予約ボタンが一斉に押せるようになります。**

### 例4：FAQを1つ増やす

```ts
export const faqs = [
  {
    q: '運動が苦手でも大丈夫ですか？',
    a: 'はい。むしろ運動習慣のない方こそ対象です。…',
  },
  {                                    ← ここから
    q: '駐車場はありますか？',
    a: '専用の駐車場はございません。近隣のコインパーキングをご利用ください。',
  },                                   ← ここまでを追加
];
```

**`{` から `},` までをひとかたまりでコピーして、中身を書き換えるのが安全です。**

## 壊さないための3つのルール

### 1. `'` と `,` は消さない

```ts
name: '月4回 定期コンディショニング',
      ↑                          ↑ ↑
      文字はこの2つの ' で挟む      最後のカンマも必要
```

### 2. 文章の中に `'` を使いたいときは `\` を前に付ける

```ts
a: 'これは\'引用\'です',
```

面倒なら、**文章の中では `'` の代わりに「」を使ってください。**

### 3. 迷ったら消さずにコメントアウト

行の先頭に `//` を付けると、その行は無かったことになります。

```ts
// '静かな空間で、ゆっくり過ごしたい',
```

**消すより安全です。** 戻したくなったら `//` を消すだけ。

## 直せないもの（私に頼んでください）

| やりたいこと | 場所 |
|---|---|
| セクションの**並び順**を変える | `src/app/page.tsx` |
| **色**を変える | `src/app/globals.css` |
| セクションを**追加・削除**する | `src/components/site/` |
| **写真**を入れる | `public/` に置いて `profile.photo` を設定 |
| 利用規約・プライバシーポリシー | `src/app/terms/page.tsx` / `privacy/page.tsx` |

## 直したあと、人に見せたい

```bash
npm run build:preview
```

`preview/` に3つのHTMLができます。**これはそのまま誰かに送っても単体で開けます。**

私に頼めば、共有できるリンクとして公開し直すこともできます。

## うまくいかないときは

**`npm run dev` でエラーが出て真っ白になった場合**、たいてい `'` か `,` の付け忘れです。

ターミナルに出ているエラーの**行番号**を見て、その行の前後を確認してください。
分からなければ、**エラーの文面をそのまま私に貼ってください。** どこが原因か見ます。

**最悪の場合でも、`git checkout src/config/site.ts` と打てば直前の状態に戻ります。**
