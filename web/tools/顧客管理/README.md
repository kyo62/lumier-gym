# TONEKA 顧客管理（施術者用・単体ファイル）

`index.html` をブラウザで開くだけで動く、1ファイルの顧客管理ツールです。サーバーも不要です。

- **HP（`web/src`・`web/public`）には含めていません。** 公開サイトからリンクしません。ネットにも出しません。
- データは、その端末のブラウザ（localStorage）にだけ入ります。バックアップ（合言葉つきの暗号化）を必ずとってください。
- 最初に入っているのは**架空のデモデータ**です。「デモを消して、自分のデータで始める」で消せます。
- **実在のお客様の情報は、このリポジトリ（公開）に絶対に入れないでください。**

設計の判断・改善点は [`02_Engineer/顧客管理ページ設計.md`](../../../02_Engineer/顧客管理ページ設計.md)。
