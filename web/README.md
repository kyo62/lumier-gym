# TONEKA ホームページ（LP）

名古屋・名城公園のパーソナルコンディショニングサロン **TONEKA（トネカ）** の
公式サイトです。**1枚完結型のランディングページ**として実装しています。

- **予約と決済は Square で完結**します。このサイトは予約ページへ送り出す役割です
- 完全に静的なサイト（サーバー不要）としてビルドされます

---

## 技術構成

| レイヤー | 採用 |
|---|---|
| フレームワーク | Next.js 16（App Router）/ TypeScript |
| UI | Tailwind CSS v4 / lucide-react |
| フォント | Shippori Mincho（見出し）/ Noto Sans JP（本文） |
| ホスティング | Cloudflare Pages（無料・商用可）を推奨 |

LP（ホームページ）は外部サービスへの依存がなく、**環境変数なしでそのまま動きます。**
会員ページ（`/member`）は、Supabase を設定しなくても**デモモード**で動きます（[後述](#会員ページmember)）。

## 会員ページ（/member）

お客様が、記録の入力・復習動画の視聴・予約ページへの移動をできる、**ホーム画面に追加して使うWebアプリ**です。
サイトの中の `/member` にあり、別のアプリを配る必要はありません（App Store 不要・無料）。

| 機能 | 中身 |
|---|---|
| ログイン | メールに届く**数字のコード**（パスワードなし）。会員は施術者が登録する |
| 記録 | 体組成（体重・体脂肪率・筋肉量）／食事／トレーニング。グラフ・一覧・削除 |
| 動画 | 復習用の動画（YouTube・Vimeo・動画ファイルのURL）。**全員向け／選んだ会員だけ**を選べる |
| 予約 | Square の予約ページへ送り出す（自作しない） |
| 設定 | 表示名／記録の書き出し（JSON）／記録の全削除／同意の取り消し／ホーム画面への追加の案内 |
| 施術者メニュー | 動画の登録と割り当て／会員の記録の閲覧（**閲覧のみ**） |

### すぐ触ってみる（デモモード）

Supabase の設定がないと、自動でデモモードになります。データは**その端末のブラウザの中にだけ**保存されます。

```bash
npm run dev        # http://localhost:3000/member
```

- ログイン：どのメールアドレスでも、コードは **`123456`**
- `admin` で始まるメールアドレス（例：`admin@example.com`）でログインすると、施術者メニューも見られます

### 本番にする手順（Supabase）

**⚠️ 手順4より前に、会員にURLを教えないでください。** 設定が終わるまでは、誰のデータも預かれません。

1. **Supabase のプロジェクトを作る**（https://supabase.com ／ 無料プランで始められます）
   - **リージョンは「Northeast Asia (Tokyo)」を選ぶ**（データの置き場所を日本にできます。選んだら、プライバシーポリシーの「国外にある場合があります」の文を実態に合わせて直してください）
2. **テーブルとアクセス制御を作る**
   - ダッシュボードの **SQL Editor** に、[`supabase/migrations/001_member_area.sql`](./supabase/migrations/001_member_area.sql) の中身を貼って実行（1回だけ）
   - これが**会員のデータを守る本体**です。実行しないまま公開してはいけません
3. **ログインの設定**（Authentication）
   - **新規登録（Allow new users to sign up）をオフにする** ← 必ず。オンだと、誰でも会員になれてしまいます
   - **メールのテンプレート（Magic link）に、数字のコードを入れる。** 標準のままだとリンクだけが届き、コード入力ではログインできません
     ```html
     <h2>TONEKA 会員ページ</h2>
     <p>ログイン用のコードです。会員ページの入力欄に入れてください。</p>
     <p style="font-size:24px;letter-spacing:6px"><b>{{ .Token }}</b></p>
     ```
   - **メールの送信元（SMTP）を設定する。** Supabase 標準の送信は回数がとても少なく、会員が増えるとログインコードが届かなくなります（Resend などの無料枠が使えます）
   - 画面の名称は、Supabase の更新で変わることがあります
4. **自分（施術者）を管理者にする**
   - Authentication → Users → **Add user → Create new user**（自分のメールアドレス。**Auto Confirm User にチェック**）
   - SQL Editor で、次を実行（メールアドレスは自分のものに）
     ```sql
     update public.profiles set is_admin = true
      where id = (select id from auth.users where email = 'あなたのメールアドレス');
     ```
5. **サイトに接続情報を渡す**
   - Supabase の **Project Settings → API** から、Project URL と **anon（公開）キー** を控える
   - Cloudflare Pages の環境変数（ビルド時）に設定して、再デプロイ
     ```
     NEXT_PUBLIC_SUPABASE_URL      = （Project URL）
     NEXT_PUBLIC_SUPABASE_ANON_KEY = （anon キー）
     ```
   - **`service_role` キーは、絶対にサイトに入れない・リポジトリに書かない**（すべての権限を持つ鍵です）。anon キーは公開されて構わない設計で、データを守っているのは手順2のアクセス制御です
6. **動作確認**（本番のURLで、実際に）
   - 自分のメールアドレスでログイン → 施術者メニューが出る
   - 別のメールアドレスの会員を1人作って、ログインし、記録を入れる → 施術者メニューの「会員の記録」に出る
   - その会員から、別の会員の記録が見えないこと
7. **会員を追加する**：手順4の「Create new user」で、会員のメールアドレスを登録します（Auto Confirm User にチェック）。登録した方は、メールにコードが届くようになります

**無料プランの注意：** Supabase の無料プロジェクトは、**1週間アクセスがないと一時停止**します。会員が使っていれば止まりませんが、最初のうちは要注意です（止まったら、ダッシュボードから再開できます）。

### 動画の登録

施術者メニュー →「動画の管理」から登録します。

- **YouTube の「限定公開」**は、URLを知っている人なら誰でも見られます（会員限定にはなりません）
- より厳密に守りたいときは、**Vimeo のドメイン制限**や、有料の動画配信サービスを検討してください
- 動画の下には、痛みを感じたら中止する旨の**注意書きが毎回自動で出ます**

### 個人情報について（重要）

- 会員が入力した記録は、**ご本人の同意を得るまで、1件も保存できません**（アプリとデータベースの両方で強制）
- 施術者は記録を**閲覧のみ**できます（書き換え・削除はできません）
- 会員は、設定から**記録の書き出し・全削除・同意の取り消し**をいつでもできます
- **`/privacy` と `/terms` を、会員ページの内容に合わせて更新済みです。** ただし公開前に、専門家（弁護士・行政書士など）の確認を受けてください
- 会員のデータは、**このリポジトリ（公開）には絶対に入れないでください**

### テスト

```bash
npm test           # ロジックとデモ用データ層のテスト（Node 22 以上）
npm run test:db    # アクセス制御（RLS）のテスト。使い捨ての PostgreSQL 16 で、他人の記録が見えないこと等を確認
```

`npm run test:db` は、`supabase/migrations/001_member_area.sql` を変更したら、必ず実行してください。

### アイコンを差し替える

ホーム画面に置かれるアイコンは、**仮のもの**です（頭文字の「T」）。ロゴが決まったら、`public/icons/` の4つのPNGを差し替えてください。

| ファイル | 大きさ | 用途 |
|---|---|---|
| `icon-192.png` / `icon-512.png` | 192 / 512px | Android など（角丸・外側は透明） |
| `maskable-512.png` | 512px | Android。端が切り取られても欠けないよう、中央60%に収める |
| `apple-touch-icon.png` | 180px | iPhone。全面塗りで、角は OS が丸める |

## 予約システムについて

以前このリポジトリには、Supabaseを使った自作の予約システム（顧客向け予約フロー・
管理画面・二重予約防止の排他制約つき）がありました。**予約をSquareで完結させる方針に
決まったため、2026-09-23 に削除しています。**

**コードはGitの履歴に残っています。** Squareが手狭になった場合は、
`git log --diff-filter=D -- web/src/app/reserve` で削除コミットを特定して復元できます。
