# 管理会社・オーナーへの連絡文案（看板・表札）

作成：2026-10-09
担当：01_Manager

> **外に出る文章（たたき台）です。** 代表が読んで、自分の言葉に直してから送ってください。
> `【 】` は、状況に合わせて入れ替えます。送ったら、返事の内容を `next_actions.md` に書いてください。
> **書面（メール）で、可否を残す**ことが目的です（`salon_opening_checklist.md` の項目）。

## 目的

- ドア前の表札と、エントランス（ポスト・集合表札など）の店名表示を、してよいかを確認する。
- 表示できる**種類と大きさ**、貼り方、費用の負担を聞く。
- Googleビジネスプロフィールで、**住所を公開**してよいかも、あわせて確認する（オーナー確認は、看板を出したあと）。

## 文案（メール）

件名：【TONEKA／【部屋番号】】店名表示（表札・案内表示）のご相談

```
【管理会社名】
【担当者名】さま

お世話になっております。
【物件名】【部屋番号】を、【10月1日】からお借りしております、伊藤京平です。

このお部屋で、個人事業として、完全予約制のパーソナルコンディショニングサロン
「TONEKA（トネカ）」を営む予定です。（開業は2027年1月を予定しています）

つきましては、次の点について、ご確認させていただけますでしょうか。

1．店名の表示
　・お部屋のドアの前に、店名の表札（小さなプレート）を出してよいか
　・エントランスの郵便受け・集合表札・案内板などに、店名を表示してよいか
　　（「TONEKA」の文字と、小さなマークのみ。広告のような大きな表示はしません）

2．表示のしかた
　・表示できる場所と、大きさの上限（縦×横）
　・貼り方（原状回復ができる方法を考えています。両面テープ、磁石、既存の差し込み枠など）
　・設置にかかる費用は、どちらの負担になるか
　・設置前に、デザインをお見せして確認が必要か

3．そのほか
　・お客様が、完全予約制で、1名ずつお越しになります。
　　来訪時に、近隣のご迷惑にならないよう、気をつけます。
　・インターネット上（Googleマップなど）に、店名とこの住所を載せることに、
　　問題がないか

お手数をおかけしますが、ご回答は、メールでいただけますと助かります。
どうぞよろしくお願いいたします。

伊藤 京平
【電話番号】
【メールアドレス】
```

## 送る前の確認（代表）

- [ ] **賃貸契約書**に、事業利用・看板・表札・来客に関する条項がないか（あれば、その条項に合わせて文を調整）。
- [ ] 電話番号・メールアドレスは、**連絡用**のもの（070の店の番号でよい）。
- [ ] 連絡先が、**管理会社**か**オーナー本人**か（契約書の連絡先を確認）。

## 返事が来たら

- 表示できる場所と大きさを、`next_actions.md` に記録する。
- 大きさが分かったら、**文字だけの仮の表札**のデザイン（TONEKA＋カタカナ）を作る。
