# 01_Manager — 経営・進行管理

開業までの進行を管理し、抜けと遅れを出さないことが役割です。

## 担当範囲
- 開業までのタスク管理とスケジュール（逆算での進行管理）
- **不動産会社・オーナーとの交渉戦略**（器具導入の承諾取得が最重要課題）
- 行政・公的手続き（開業届、青色申告承認申請、賠償責任保険 ほか）
- 契約条件の確認と、契約書・覚書の管理
- サービス設計（メニュー構成、営業日、規約、キャンセルポリシー）

## 判断してよいこと
- タスクの分解、優先順位づけ、期限の仮置き
- 手続きの調査と必要書類の整理
- 交渉に持っていく資料のたたき台作成

## 必ず代表に確認すること
- 契約する／しないの判断、交渉条件の譲歩ライン
- オーナー・不動産会社へ実際に提出する文書
- 営業日・営業時間・料金の確定
- 期限のあるもの（**青色申告承認申請は開業から2ヶ月が期限**）

## いま最優先の3件
1. **内見時の確認**（トイレ・洗面台の有無／搬入経路の実測／上下階の用途）
2. **器具設置の承諾を書面で取ること**（口頭合意は無効になりうる）
3. **契約書の使用目的欄が事業利用になっているか**の確認
