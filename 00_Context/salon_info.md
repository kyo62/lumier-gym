## サロンのコンセプト

**整体・ストレッチをメインとした、姿勢改善のプライベートサロン。**

- ハードな筋力トレーニングを行うジムではありません
- 完全予約制の1対1。他のお客様と顔を合わせません
- 週に数日のみの営業、低固定費モデルで運営します

| 項目 | 内容 |
|---|---|
| 物件名 | レジデンス清水 |
| 所在地 | 名古屋市北区 |
| 物件種別 | リノベーション済みのスモールオフィス向け物件 |
| 設備 | **バス・キッチンなし** |
| 家賃 | 3.5万〜4万円前後 |
| 状態 | 契約に向けて交渉中 |

### 注意すべき前提
- バス・キッチンがないため、**洗面台・トイレの有無を必ず確認**すること（施術業では手指衛生の導線が必須）
- マンションの一室のため、**上下階・隣室への音と振動**が最大のリスク
- **事業利用（SOHO）が可能な契約になっているか**の確認が必須

## 設備

| 項目 | 内容 |
|---|---|
| 主要器具 | ボディメーカーのベンチプレス **1台** |
| 用途 | 胸を開くストレッチ／低負荷でのフォーム修正の**補助具** |
| 用途でないもの | 高重量トレーニング、バーベルの落下を伴う種目 |

**この位置づけは絶対に外さないでください。**
「ジムにベンチプレスがある」と説明すると、オーナー交渉でも集客でも意図と違う伝わり方をします。
正しくは「ストレッチとフォーム修正を安全に行うための台が1台ある」です。

## オーナーとの交渉条件

マンションでの器具導入に対する懸念を払拭するため、以下を条件として提示・実施します。

- 床に **20mm厚以上のプロ仕様の硬質ラバーマット** を敷く
- あわせて **コンパネ（構造用合板）** を敷き、**荷重を面で分散** させる
- **防音・防振対策を徹底** する
- バーベルの落下・投げ下ろしは一切行わない（運用ルールとして明示）

### 交渉時の原則
- **口頭合意で終わらせない。** 器具設置の承諾は覚書または契約の特約として書面で残す
- 「1対1の施術サロン」として説明する（「ジム」と言わない）
- 施工後は写真をオーナーへ共有し、約束どおり実施した証跡を残す

詳細な交渉手順は `01_Manager/salon_opening_checklist.md` の「2. オーナー交渉」を参照。
