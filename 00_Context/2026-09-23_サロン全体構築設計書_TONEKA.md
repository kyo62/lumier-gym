## 2. メニュー・料金設計

入会金・事務手数料は全プラン無料（0円）。決済は **Square**（クレジットカード定期課金・店頭キャッシュレス）。

| プラン | 料金（税込） | 内容 |
|---|---|---|
| 月4回 定期コンディショニング | **30,800円/月**（1回 7,700円） | 週1回ペース。主力プラン |
| 月2回 メンテナンス | **16,000円/月**（1回 8,000円） | 隔週ペース |
| 都度ビジター（店舗50分） | 12,000円/回 | 単発・不定期 |
| オンラインパーソナル（50分） | 12,000円/回 | 遠方・自宅から |
| ペア同時受講（60分） | お一人 7,700円（2名 15,400円） | 親子・夫婦・友人で1枠シェア |
| 家族割（月額個別通い） | 各月額から **5% OFF** | 家族それぞれが個別枠で通う場合 |

### 安心サポート制度
- **翌月末自動繰り越し**：当月未消化の枠は追加料金なしで翌月末日まで繰り越し可能
- **期限直前のオンライン振替救済**：期限切れになりそうな場合、1回30分の
  「オンライン呼吸・姿勢リセット」へ振替消化が可能（月最大2回まで）

## 4. ホームページ（LP）要件

- **形式：1枚完結型（HTML＋CSS一体型コード作成済み、レスポンシブ対応）**
- トーン＆マナー：和モダン・ミニマル（温かみのあるグレージュ、チャコールグレー、真鍮ゴールドアクセント）

### 構成
1. **ファーストビュー**：「がんばる前に、まず整える。」／名城公園駅徒歩すぐの完全個室／予約CTA
2. **お悩みチェック**：首肩こり、姿勢崩れ（反り腰・猫背）、もみほぐしで数日で戻る、ハードな筋トレは苦手、静かな空間を好む
3. **選ばれる3つの理由**：「脱力」から始めるコンディショニング／カフェのような完全個室／セッション後のアフターティー
4. **セッションの流れ（ゆったり90分枠）**：お迎え・着替え → カウンセリング → 骨格・呼吸の調整 → 連動チェック → お茶＆振り返り
5. **メニュー・料金案内**：月4回、月2回、都度、ペア・家族割、繰り越しサポート制度
6. **サロン概要・アクセス**：名城公園エリア、完全予約制、手ぶらOK
7. **予約導線**：**Square予約リンクへ直接連動**

## 5. Instagram運用方針（実店舗特化型）

フォロワー数ではなく、**名城公園周辺・北区・東区・中区の生活圏にいる大人の女性**の集客に特化。

### プロフィール設計
- 名前：**【名城公園】大人の身体を整えるサロン TONEKA**
- 訴求：激しい筋トレなし／呼吸と骨格リセット／更衣スペース完備／セッション後のお茶付き
- 導線：Square初回体験予約リンク

### 投稿フォーマットの役割分担
| 種別 | 頻度 | 役割 |
|---|---|---|
| フィード | 週1〜2回 | サロンの信頼カタログ。内装空間、窓際カウンター、手書き感想、姿勢変化の写真 |
| リール | 週2〜3回 | 地域見込み客の認知獲得。30〜50代女性向けの簡単セルフケア（末尾に必ず「名城公園のプライベートサロンTONEKA」の映像） |
| ストーリーズ | 毎日 | 人柄と親しみやすさ。本日のお茶、日常のつぶやき、週の空き枠案内 |

### ローカルアクション
- 全投稿に位置情報（「名城公園」「名城公園駅」）を設定
- 近隣のカフェ、パン屋、ショップ等の地域アカウントをフォロー・紹介し、地域内で認知を循環させる
