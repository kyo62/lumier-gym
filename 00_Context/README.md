# 00_Context — ナレッジ・共有情報

全AI社員が参照する**前提知識**の置き場所です。ここは「決まったこと」だけを書きます。

## 置くもの
- 代表者の経歴、サロンのコンセプト、物件・設備の情報（`salon_info.md`）
- 確定した意思決定の記録（何を・いつ・なぜ決めたか）
- 契約条件、オーナーとの合意事項など、後から参照する必要がある事実

## 置かないもの
- 検討中のアイデアやたたき台（各担当フォルダへ）
- 数字の試算（`04_Finance/` へ）

## ルール
- **未確定のことを確定として書かない。** 迷ったら `salon_info.md` の「未確定事項」に置く
- 前提が変わったら**古い記述を残さず更新する**（履歴はGitが持っています）
- 更新したら、内容が影響する担当（Manager / Engineer / Marketer / Finance）に何が変わったかを伝える

## ファイル
- [`salon_info.md`](./salon_info.md) — サロン基本情報（**全員必読**）
- [`これまでの経緯.md`](./これまでの経緯.md) — 全記録。決定事項・却下した案と理由・訂正・時系列
